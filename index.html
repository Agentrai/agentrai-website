Platform Features
One platform, six AI-powered workflows

AgentRai replaces disconnected tools with a coordinated system that captures, structures, and acts on care data automatically.

Voice-to-Note ETL
Caregiver speaks → local Whisper transcribes (on-device, no audio leaves device) → Gemini structures anonymized text into a typed care note → saved to PostgreSQL.
Data Engineering
Shift Handover Agent
RAG-powered handover summaries generated at 06:30 daily. Retrieves recent observations, incidents and flags via agentic memory.
Multi-Agent
Family Portal
Dedicated parent view with AI-generated daily reports, observations, and two-way messaging. Separate JWT-secured access.
RBAC
Compliance Agent
Nightly scan at 21:00 checks documentation against SGB VIII/IX standards. Flags incomplete records before deadlines.
Scheduler
Feature Store + Analytics
Per-child wellness scores, mood stability index, medication compliance rate. Time-series trends with SSE streaming dashboard.
ML Features
Full-Text Search
Cross-observation and incident search with configurable time windows. Data quality scoring (0–100) with field-level validation.

Agent Architecture
7 specialized agents, one orchestrator

Each agent handles a specific care workflow. The orchestrator routes requests and coordinates multi-agent tasks.

Documentation Agent
Voice transcript → structured care note (EN/DE)
Handover Agent
RAG shift summaries with agentic memory retrieval
Reminder Agent
Missing field detection, 06:00 daily alerts
Family Agent
Parent-facing RAG communication, 14-day context
Compliance Agent
SGB VIII/IX nightly checks, 21:00 scheduler
Observation Agent
Structured special-needs behavioral logging
Daily Report Agent
Auto parent report from observations, 17:00 daily
