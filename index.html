AI Technology
6 AI agents working for your team
Each agent has a specific job. They share memory, coordinate automatically, and run 24/7 in the background.
🎙️ Documentation Agent
Converts spoken transcripts into structured care notes. Detects missing fields, assigns urgency levels, and flags for review. Supports German and English.
🔄 Handover Agent (RAG)
Retrieves the last 10 approved observations before generating a shift summary. Uses real documented history — never invents information. Updates agentic memory after every run.
📊 Daily Report Agent
Reads all observations from the day and generates a warm parent update. Runs automatically at 17:00 for every active child. Bilingual output.
✅ Compliance Agent
Checks documentation against SGB VIII/IX standards every night. Flags overdue mobility assessments, missing family updates, and incomplete records. Generates compliance reports.
🔔 Reminder Agent
Scans recent observations for missing critical fields. Runs at 06:00 to alert staff before the shift starts. Prevents incomplete documentation before it becomes a compliance issue.
💬 Family Communication Agent
Generates warm, non-clinical family updates from the last 14 days of approved observations. Converts clinical language into readable summaries parents actually understand.
